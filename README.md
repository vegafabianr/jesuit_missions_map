# Misiones jesuíticas de Sudamérica

**[Ver el mapa →](https://vegafabianr.github.io/jesuit_missions_map/)**

Mapa interactivo de 94 misiones jesuíticas de Sudamérica: Guaraníes, Chiquitos, Moxos, Chaco, Maynas, Los Llanos-Casanare, Chiloé y Bío-bío. Cada punto es una misión; al hacer clic o tocarlo aparece su nombre. El color indica el conjunto misional.

*Interactive map of 94 Jesuit missions in South America. Click or tap a point to see the mission's name; colors mark the mission groups.*

Hecho con [Folium](https://python-visualization.github.io/folium/) (Leaflet). El mapa completo está en `index.html`.

Para las bibliotecas de estas misiones, ver [Las bibliotecas de las misiones jesuíticas de la Sudamérica hispánica (1767–1768)](https://vegafabianr.github.io/jesuit-missionary-libraries/).
